# Projectile Trajectory Fix

Small addon for [Projectile Trajectory](https://mods.vintagestory.at/speartrajectory), on 1.22.7 its line was a bit off for vanilla spears and bows and with [Combat Overhaul Fork](https://mods.vintagestory.at/combatoverhaulfork) it didn't work at all, this patches it so the line lands where your shot does

Install it with the original mod,we couldn't make a fork because the mod has no license sadly.
